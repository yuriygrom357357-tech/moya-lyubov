# Моя Любов 💗

Красиві фото малюка до кожної віхи — вебзастосунок (PWA), що встановлюється на iPhone та Android.

- Віхи від 1 тижня до 5 років, «Перші моменти», нагадування в календар
- Фотостудія: вирізання фону на пристрої, 12 сцен, написи віх 11 мовами, прикраси, стікери
- ШІ-фотосесія (Google Gemini, ключ користувача)
- Альбом, «до/після», «Тоді і зараз», відео «Історія росту», лист у майбутнє
- Усе зберігається лише на пристрої користувача

Мови: українська, English, Deutsch, Français, Español, Italiano, Português, Polski, עברית, 日本語, 中文.
